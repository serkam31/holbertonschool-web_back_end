# Python Async Function

Asynchronous programming in Python using `async`/`await`, `asyncio`, and coroutine-based concurrency.

## Requirements

- Python 3.9 — Ubuntu 20.04 LTS
- pycodestyle 2.5

## Tasks

| # | File | Description |
| --- | --- | --- |
| 0 | `0-basic_async_syntax.py` | Coroutine that waits a random delay and returns it |
| 1 | `1-concurrent_coroutines.py` | Run `n` coroutines concurrently with `asyncio.gather` |
| 2 | `2-measure_runtime.py` | Measure total execution time of concurrent coroutines |
| 3 | `3-tasks.py` | Create and return an `asyncio.Task` |
| 4 | `4-tasks.py` | Replicate concurrent coroutines using Tasks |

## Usage

```bash
python3 0-main.py
python3 1-main.py
```
